# Hospital Data Analysis – Excel & SQL

## 1. Project Overview

This project focuses on analyzing hospital data using Microsoft Excel and MySQL. The objective is to examine patient distribution, hospital performance, department-wise patient volume, and medical expenses to identify meaningful business insights.

## 2. Project Objectives

- Analyze patient volume across hospitals and departments.
- Understand location-wise patient distribution.
- Examine hospital medical expenses.
- Calculate average patient length of stay.
- Identify patterns and trends in hospital operations.

## 3. Tools & Technologies

- **Microsoft Excel** – Data analysis, formulas, and calculations.
- **MySQL** – Data querying, aggregation, and analysis.

## 4. Dataset Information

The dataset includes the following fields:

- Hospital Name
- Location
- Department
- Doctors Count
- Patients Count
- Admission Date
- Discharge Date
- Medical Expenses

## 5. Excel Analysis

Excel formulas were used to perform calculations and analyze hospital data.

Key analysis areas:
- Total patients and medical expenses.
- Average doctors count.
- Length of hospital stay.
- Expense per patient.
- Department-wise patient analysis.
- Location-wise patient analysis.

**Excel documentation:** [View Excel Analysis PDF](./Excel-Analysis.pdf)

## 6. SQL Analysis

MySQL queries were used to perform structured data analysis.

Key concepts covered:
- Aggregate Functions
- GROUP BY and ORDER BY
- HAVING
- SUMIF-style analysis using SQL aggregation
- Date Functions
- Common Table Expressions (CTEs)
- Window Functions and DENSE_RANK()
- Hospital-wise and department-wise analysis

## 7. Key Business Questions

- Which department has the highest patient volume?
- Which hospital handles the most patients?
- Which location has the highest patient count?
- Which hospital has the highest medical expenses?
- What is the average length of hospital stay?
- How do medical expenses vary by month?

## 8. Project Outcome

This project demonstrates the use of Excel and MySQL for hospital data analysis. It helps examine patient volume, department performance, location distribution, and medical expenses to support data-driven operational insights.
